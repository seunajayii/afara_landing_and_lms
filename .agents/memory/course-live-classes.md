---
name: Course live classes
description: How scheduled live teaching belongs in both course curriculum and the shared event calendar.
---

Live classes are lessons linked to the existing event system, not a separate course-only scheduling model. The linked event owns the date, meeting details, Zoom lifecycle, and facilitator assignments; a live class can have zero or more facilitators while staffing is still pending.

**Why:** Participants need scheduled teaching to appear in the context of a module while the programme team still needs one authoritative event for calendars, Zoom, recordings, and attendance.

**How to apply:** Create or update the linked event from the course lesson workflow, expose its schedule and facilitator names in course content, and display a clear pending/unassigned state when none are selected. Learners must only see linked events while the parent course is published and accessible. Deleting a live-class lesson, its module, or its course must also delete the linked event so calendar and dashboard cards cannot outlive the curriculum item. Preserve the event as the source of truth while the live class exists.
